# Spelljam

A spelling-song app for kids around 9 and 11. Each English word gets its own tune. The letters are sung in the same order every time, so the song is how the spelling sticks.

Words stay on the device. A grown-up can download a backup file and open it on another tablet. There is no account and no database password in the app.

## Try it

Open the app, tap a word, and press the gold play button. Sing the letters out loud. Then tap **Your turn** and spell it for stars.

The **Grown-up shelf** is where school units get typed in, one word per line:

```
party — a fun get-together
friend — someone you like
```

The meaning can be in any language. It is shown as a clue, not sung.
